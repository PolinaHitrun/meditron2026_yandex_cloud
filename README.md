# Решение кейса YandexCloud: Пакетная обработка выписных эпикризов

Данный репозиторий содержит прототип решения для автоматического извлечения 50 кардиологических признаков из неструктурированных выписных эпикризов пациентов с ОКС. Итоговый результат формируется в виде строго типизированных JSON-файлов.

## Архитектура решения

Пайплайн построен на гибридном подходе (Rule-based + ML), что обеспечивает максимальную точность и полноту извлечения:
1. **Rule-based модуль (Регулярные выражения):** Отвечает за извлечение жестко структурированных данных с околонулевой вероятностью ошибки (показатели гемодинамики, ЧСС, лабораторные анализы, фракция выброса).
2. **ML NER (RuBERT Token Classification):** Дообученная модель семейства BERT сканирует текст по предложениям и извлекает сложный медицинский контекст, который пропустили регулярные выражения (названия диагнозов, медикаментозная терапия, локализации инфаркта).
3. **Постпроцессор-нормализатор:** Приводит извлеченные сырые данные к формату организаторов (бинарные флаги `0/1`, коды `Y/R/N` для коронарографии, очистка чисел от единиц измерения, фильтрация лишних слов).

## Требования и установка

Рекомендуемая версия Python: **3.10+**

Клонируйте репозиторий и установите необходимые зависимости:

```bash
git clone https://github.com/PolinaHitrun/meditron2026_yandex_cloud/tree/main
cd meditron2026_yandex_cloud
pip install -r requirements.txt
```

## Загрузка весов модели

Из-за ограничений Git на размер файлов, веса дообученной нейросети хранятся в облаке. Для успешного запуска пайплайна необходимо:

1. Скачать архив с весами модели по [ссылке](https://disk.360.yandex.ru/d/MqBPxvPJnLuBsQ)
2. Распаковать архив.
3. Поместить папку `final_medical_ner_model` в **корень** данного репозитория.

Убедитесь, что внутри папки `final_medical_ner_model` лежат файлы `config.json`, `model.safetensors` и конфигурации токенизатора.

## Запуск пайплайна

1. Поместите входные текстовые документы (`.md` или `.txt`), которые нужно обработать, в папку `input/`
2. Запустите главный скрипт:

```bash
python pipeline.py
```

Скрипт автоматически:
* Прочитает все документы в папке.
* Проведет гибридное извлечение сущностей.
* Создаст валидные JSON-файлы.
* Сохранит их в директорию `result/` в корне проекта.

## Структура проекта

* `pipeline.py` — точка входа, объединяющая регулярные выражения, ML-модель и форматирование JSON.
* `src/` — исходный код пайплайна на правилах (сегментация, регулярные экстракторы).
* `finetuning/` — скрипты для генерации синтетических данных, подготовки датасетов в BIO-формат и обучения BERT-модели.
* `final_medical_ner_model/` — директория для весов обученной модели (скачивается отдельно).
* `input/` — директория для входных документов.
* `result/` — директория с готовыми JSON-файлами для отправки в проверяющую систему.
